# Генерация картинок и анимаций для ShrekParty

Всё, что нужно, чтобы самому рисовать в ComfyUI в одном стиле с приложением.

```
comfy/
├── README.md            ← этот файл
├── prompts.md           ← все промты: боссы, анимации, эффекты, иконки вместо эмодзи, капча
├── voice.md             ← реплики боссов для ElevenLabs
├── workflows/
│   ├── 01-zimage-new-picture.json     ← новая картинка из текста
│   ├── 02-qwen-edit-boss-pose.json    ← та же картинка, другая поза/состояние
│   └── 03-ltx-animate-from-image.json ← анимация из картинки
├── notes/               ← пояснения к нодам (они же лежат заметками внутри воркфлоу)
├── source/              ← нынешние боссы на хромакей-фоне — исходники для 02
├── examples/            ← пробный результат: Фаркуад, стадия hp2 из воркфлоу 02
└── tools/key.py         ← вырезает хромакей-фон в прозрачность
```

## Как открыть воркфлоу

Они уже лежат в ComfyUI: левая панель → **Workflows** → папка **shrek**.
Если пропадут — перетащи json из `workflows/` прямо в окно ComfyUI.

Исходники боссов (`farquaad-hp100.png`, `fairy-hp100.png`, `peasant-hp100.png`) уже загружены в ComfyUI → input.
Их видно в списке у ноды Load Image.

Все модели уже скачаны, ничего докачивать не надо.

| Воркфлоу | Модель | Для чего | Время на 5070 |
|---|---|---|---|
| 01 | Z-Image Turbo | всё новое: иконки, эффекты, предметы, фоны | ~10 с |
| 02 | Qwen Image 2.1 Edit | боссы: стадии по здоровью, удар, ходы, победа/поражение | ~40 с |
| 03 | LTX-2.3 (22B) | короткие ролики: дышит, бьёт, получает удар | несколько минут |

Внутри каждого воркфлоу есть рыжая заметка: что делает каждая нода и что в ней можно крутить. Тот же текст лежит в `notes/01.md`, `02.md`, `03.md`.

## Порядок работы над боссом

1. **Стадии здоровья** (02). hp1 — нынешняя картинка, она уже есть. Из неё делаешь hp2, а hp3 — **из hp2**, чтобы раны копились.
2. **Удар** (02): hurt1/hurt2/hurt3, каждый из своей стадии.
3. **Ходы** (02): move-* из hp1.
4. **Победа/поражение** (02): victory из hp1, defeated из hp3.
5. **Анимации** (03), если хочется. Первый кадр — картинка из шагов 1–4, ещё с зелёным фоном.
6. **Вырезать фон** у картинок (ниже) и сложить в `web/public/assets/boss/<босс>/`. Имена — в таблице в `prompts.md`.
7. Скажи мне — подключу. На ТВ босс будет меняться по здоровью, при ударе и на своём ходу.

Делай 2–3 варианта (меняй seed) и выбирай лучший. Больше обычно не нужно.

## Как писать промт

Подробно — в заметках к воркфлоу. Коротко:

- **Только по-английски**, одним абзацем.
- **Новая картинка (01):** стиль → что нарисовать → детали и цвета → фон → чего нет. Стиль и фон — готовые куски STYLE / ICON / BG_GREEN из `prompts.md`, копируй их как есть: на них держится единый вид.
- **Правка (02):** это **инструкция**. KEEP (что сохранить) → **что изменить, видимыми деталями** («бинт на голове», а не «выглядит слабее») → BG_KEEP. Одна правка за раз.
- **Анимация (03):** сценарий по времени: стиль → кто → что делает по шагам → камера неподвижна → фон не меняется. Одно действие на ролик. Для зацикленного ролика — `returns to exactly the same pose as at the start`.
- **Фон всегда хромакей:** зелёный `#00ff00`. Если в объекте есть зелёное (лук, лягушка) — пурпурный `#ff00ff`. У Крестьянина фон пурпурный.
- **Палитра приложения:** navy `#0a1824`, lamp yellow `#ffd166`, coral `#ef6f5e`, mint `#6ee7b7`, sky `#9cc3e6`, cream `#fff6df`. Называй цвета этими кодами.
- Персонажи на ТВ стоят друг напротив друга: **боссы смотрят влево, питомцы — вправо**. Пиши это в промте.

## Вырезать фон

Картинка. Нужны ffmpeg и python, оба уже стоят. Сначала уменьшить до 384, потом вырезать:

```bash
ffmpeg -y -i boss_00001.png -vf scale=384:-1 small.png
```
```bash
python comfy/tools/key.py small.png hp2.png green
```

Для пурпурного фона последний аргумент — `magenta`. Скрипт печатает `corners=[0, 0, 0, 0]` — значит, углы прозрачные и всё вырезалось.

Видео → webm с прозрачностью (браузер такое показывает):

```bash
ffmpeg -y -i LTX_00001.mp4 -vf "chromakey=0x00ff00:0.18:0.06,despill=green,scale=512:-1" -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 32 -an idle.webm
```

Для пурпурного фона — `chromakey=0xff00ff:0.18:0.06` (без despill). Можешь просто скинуть мне mp4/png — вырежу и подключу сам.

## Куда что класть

| Что | Папка |
|---|---|
| Боссы: стадии, удары, ходы | `web/public/assets/boss/<босс>/` |
| Анимации боссов | `web/public/assets/boss/<босс>/anim/` |
| Эффекты боя | `web/public/assets/fx/` |
| Иконки вместо эмодзи | `web/public/assets/icons/` |
| Капча (фото, jpg) | `web/public/assets/captcha/` |
| Озвучка боссов (mp3) | `web/public/assets/voice/boss/` |

Точные имена файлов — в таблицах `prompts.md` и `voice.md`. Новые картинки начнут показываться в приложении, когда я подключу их в коде.
