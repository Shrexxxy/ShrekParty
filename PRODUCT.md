# Product

## Platform

web

## Users

- **Гости** (~10 человек, друзья именинника) — с личных смартфонов. Вечер в арендованном коттедже, тусклый свет, многие навеселе. Регистрируются, играют в ивенты, ставят ослики, выращивают драконоосликов, дерутся с боссами.
- **ТВ** — обычный телевизор в гостиной, гости смотрят с 2–4 м. Показывает текущий ивент, табло, бой с боссом.
- **Ведущий (именинник Дмитрий)** — пульт с телефона: запускает и ведёт ивенты, видит всё.

## Product Purpose

Одноразовое приложение-игра на день рождения Дмитрия (06.11.2026): программа вечера из мини-игр и ивентов с общей валютой «ослики». Успех — гостям весело, всё понятно без объяснений, ничего не тормозит и не ломается в моменте.

## Positioning

Сделано под конкретную компанию: в регистрации, мафии, боях и аукционе — свои люди, свои фото, свои шутки. Тема — мир Шрека (болото, ослики, Фаркуад, Фея-крёстная).

## Operating Context

- Вечер, коттедж, без декора — просто застолье. Свет тусклый.
- Гости навеселе: всё должно читаться крупно и нажиматься без промахов.
- ТВ — главный общий экран в шумной комнате; телефоны — личные пульты гостей.
- Регистрация-ловушка (капча, «простой пароль»), турниры с тотализатором, Смехлыст, прятки, фотоохота, реакция, тапалка, «сколько мне дней», нейрофото, Своя игра, мафия с ночными заданиями, драконоослики и бои с боссами (крестьянин, Фаркуад, Фея-крёстная), церемония, аукцион.

## Capabilities and Constraints

- Стек: ASP.NET Core .NET 10 + SignalR + EF Core SQLite; фронт React 19 + Vite + TypeScript; один Docker-образ.
- Все экраны обновляются в реальном времени из снапшота сервера.
- Узнаваемого Шрека нейросети рисовать отказывались — персонажей делаем «в духе», без копирования образов.
- Картинки: часть рисует Claude (SVG), часть генерирует Дмитрий в нейросети по промптам Claude — решаем по ходу для каждой.

- Названия и тон — шутливые, по-русски, «болотные».
- Выбранное направление оформления: «Ярмарка Тридевятого королевства» (решение Дмитрия; детали — в DESIGN.md).

## Product Principles

1. Читается через комнату: на ТВ — крупно и контрастно, на телефоне — с одного взгляда.
2. Пальцем навеселе не промахнуться: крупные цели, мало мелкого текста, ничего важного по краям.
3. Праздник, а не сервис: у каждого экрана характер, но не за счёт понятности.
4. Свои люди в кадре: фото, аватары и имена гостей важнее абстрактной графики.

## Accessibility & Inclusion

Тусклый свет и гости навеселе: высокий контраст, крупный текст, большие зоны нажатия, никакой информации только цветом.
