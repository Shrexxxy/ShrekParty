# Боты для репетиции

Консольная программа, которая запускает N ботов-гостей. Каждый бот регистрируется как обычный гость, подключается к живому каналу и сам играет в текущий ивент: ставит, тапает, голосует, дерётся с боссом. Нужна, чтобы прогнать вечер без живых людей и посмотреть, как всё выглядит на ТВ и телефонах.

## Что нужно

- **.NET 10 SDK** на компьютере, откуда запускаешь (`dotnet --version` — 10.x).
- **Запущенный сервер приложения** — локально (`http://localhost:5000`) или боевой (`https://домен`).
- Ведущий в админке: регистрация, программа, кнопки фаз — боты сами ничего не открывают и не запускают.

## Запуск

Из корня репозитория (`ShrekParty`):

```bash
dotnet run --project tools/ShrekParty.Rehearsal -- --url http://localhost:5000 --bots 10
```

Остановить — **Ctrl+C** в этом окне.

| Параметр | По умолчанию | Что это |
|---|---|---|
| `--url` | `http://localhost:5000` | адрес API. Для боевого — `https://домен` |
| `--bots` | `9` | сколько ботов |
| `--min-delay` | `1000` | минимальная «человеческая» пауза перед действием, мс |
| `--max-delay` | `6000` | максимальная пауза, мс |

Быстрая репетиция (боты реагируют почти сразу):

```bash
dotnet run --project tools/ShrekParty.Rehearsal -- --url http://localhost:5000 --bots 10 --min-delay 200 --max-delay 1000
```

## Как боты входят

1. Ждут, пока ведущий **откроет регистрацию** (`🚀 Открыть регистрацию` в админке). До этого просто ждут — запускать ботов можно заранее.
2. Проходят «регистрацию-ловушку»: слабый пароль → меняют на сильный.
3. Если бот с таким логином уже есть (ботов перезапустили) — входит под ним заново, ничего не ломается.

Логины: `Бот_Осёл`, `Бот_Фиона`, `Бот_Пряня`, `Бот_Кот`, `Бот_Дракоша`, `Бот_Фаркуад`, `Бот_Пиноккио`, `Бот_Волк`, `Бот_Гоблин`, `Бот_Мышь`, `Бот_Мерлин`, `Бот_Артур`, дальше — с номером.
Пароль у всех один — константа `Bot.StrongPassword` в `Bot.cs`. Под ним можно войти с телефона и посмотреть экран бота.

Драконоослики ботам достаются, когда ведущий закрывает регистрацию, — как у всех; яйцо боты вылупляют сами.

## Что боты делают в играх

| Ивент | Что делают |
|---|---|
| Турнир | ставят на **текущий** матч тотализатора; победитель финала решает про вызов |
| Фотоохота | шлют фото, лайкают чужие |
| Прятки | голосуют за самое смешное фото |
| Реакция | жмут после сигнала, иногда фальстартят |
| Тапалка | тапают в своём темпе |
| Сколько дней | отвечают числом |
| Нейрофото | угадывают человека и образ |
| Своя игра | выбирают вопрос, жмут кнопку, ставят и отвечают в финале |
| Аукцион | торгуются |
| Мафия | ночью — действие по роли (мафия, доктор, комиссар) или задания мирного, днём заканчивают речь и голосуют |
| Бой с боссом | выбирают ход по объявленному удару (уклон, заслон, лечение, огонь) и **подтверждают**; выбывшие поддерживают |
| Смехопанорама, Церемония | ничего — там гостю делать нечего |

Ведущий по-прежнему нужен: старт ивентов, «▶ Дальше» в мафии и Своей игре, победители матчей и т. п.

## Репетиция на боевом сервере

```bash
dotnet run --project tools/ShrekParty.Rehearsal -- --url https://домен --bots 10
```

Боты станут настоящими игроками в базе. **После репетиции** — админка → «Сбросить всё» (ввести `СБРОС`): удалит игроков (и ботов), их фото и результаты; персонал, программа, вопросы и лоты останутся.

## Частые проблемы

| Что видно | Что делать |
|---|---|
| Боты молчат, в логе ничего | регистрация ещё закрыта — открой в админке |
| Боты перестали реагировать после перезапуска сервера | если сервер лежал дольше ~минуты, боты бросают переподключаться. Останови (Ctrl+C) и запусти заново — они войдут под своими логинами |
| `→ 409 {"error":"not_active"}` в логе | бот доделывал ход в ивенте, который уже закрыли. Не страшно |
| `dotnet test` или сборка API падает «файл занят ShrekParty.Rehearsal» | боты держат сборку — останови их перед тестами |
| В лог сыпется много строк | это нормально: каждый бот пишет, что сделал (`[Бот_Волк] в бою: Cover`) |
